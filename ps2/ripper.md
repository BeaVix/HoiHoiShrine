# HoiHoiRipper
This page is dedicated to the tool used for extracting most of the files from the PS2 game, the HoiHoiRipper (tm).

[Check it out on github](https://github.com/BeaVix/HoiHoiRipper/).

{% include image-caption.html img="RipperScreenshotV1.png" alt="Screenshot of the HoiHoiRipper program" caption="HoiHoiRipper in action"%}

This tool was made by me and is currently maintained by me alone, which is why updates are slow, besides the fact that i'm not that good at reverse engineering.

## About
This program lets you visualize and extract the contents of the various propietary file formats that hold the assets used in the PS2 game.

Presently, I'm working on support for files containing 3D model data (no support for converting sound files planned, there already exist methods for dealing with these formats).

If you find bugs or have trouble with anything let me know by opening an issue on github or sending me an email, I will not make promises about the time it might take me to fix them though.
