# HoiHoiRipper
This page is dedicated to the one and only (at the momenent) tool used for extracting game assets, the *HoiHoiRipper*.


{% include image-caption.html img="RipperScreenshotV1.png" alt="Screenshot of the HoiHoiRipper program" caption="HoiHoiRipper in action"%}

This tool was made by me and is currently maintained by me alone, which is why updates are slow, besides the fact that i'm not that good at reverse engineering.

[Check it out on github](https://github.com/BeaVix/HoiHoiRipper/).

## About
This program lets you visualize and extract the contents of the various propietary file formats used in the PS2 game. To use, all you need to do is load/drag and drop a recognizable file format.
 
Current supported formats include:

- UFP
- PSI

Presently, I'm working on support for files containing 3D model data. Sound files and such can be extracted using the tool, but there already exists programs dedicated to converting them, so no plans on that.

If you find bugs or have trouble with anything let me know by opening an issue on github. Contributions are also appreciated.
