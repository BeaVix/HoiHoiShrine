# Links
Here are some links to websites relating to HoiHoi-San. As can be expected, all content is mostly in japanese.

{% include list-title.html text="Present" %}
- [Official HoiHoi-San LEGACY twitter](https://twitter.com/hoihoisanlegacy) - Remains of the present HoiHoi-San, if there's ever news, it most probably will be posted here
- <s><a href="https://twitter.com/NETONEVISIONS">Kunihiko Tanaka's twitter account</a> - Sometimes uploads new illustrations</s> Gone now, you can find most of the illustrations on this website.
- [Kunihiko Tanaka's Fanbox](https://www.fanbox.cc/@onevisions/posts) - Lots of exclusive illustrations and a few exclusive LEGACY chapters (2$/month)
- [The Cutting Room Floor's page for the PS2 game](https://tcrf.net/Ichigeki_Sacchuu!!_HoiHoi-San) - Info on how to unlock the debugging menus hidden in-game
- [My tumblr blog](https://hoihoisanlegacy.tumblr.com/) - Illustrations and manga scans. All content posted there will also be avalible on this website
